# 🗄️ Projetos de Banco de Dados

Bem-vindo(a) ao meu repositório de **Projetos de Banco de Dados**!

Este espaço foi criado com o objetivo de armazenar, organizar e documentar meus projetos práticos relacionados ao desenvolvimento e gerenciamento de bancos de dados.

Aqui compartilho minha evolução nos estudos, aplicando conceitos e conhecimentos adquiridos por meio de exercícios, desafios e projetos práticos.

## 🎯 Objetivos

- Desenvolver conhecimentos em bancos de dados.
- Praticar a linguagem SQL.
- Aprender a modelar e estruturar bancos de dados.
- Trabalhar com relacionamentos entre tabelas.
- Desenvolver consultas simples e avançadas.
- Aplicar boas práticas na organização e manipulação de dados.
- Construir projetos práticos para meu portfólio.

## 🛠️ Tecnologias e ferramentas

- **MySQL** – Criação, gerenciamento e manipulação de bancos de dados.
- **PostgreSQL** – Estudos e práticas com bancos de dados relacionais.
- **MySQL Workbench** – Modelagem e gerenciamento de bancos de dados.
- **SQL** – Linguagem utilizada para manipulação e consulta de dados.
